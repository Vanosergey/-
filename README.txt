## 📖 Описание проекта

**«Умная парковка»** — это программно-аппаратный комплекс для мониторинга и управления парковочным пространством. Система решает проблему неэффективного использования парковочных мест, помогает водителям экономить время на поиск свободного места, а администрации — управлять загрузкой.

Проект состоит из двух основных модулей:
1. **Модуль компьютерного зрения (C++)** — в реальном времени анализирует видеопоток с IP-камеры, определяет занятость мест и распознает государственные регистрационные знаки (ГРЗ) автомобилей.
2. **Telegram-бот (Python)** — предоставляет интерфейс для клиентов и владельцев парковки.

---

## ⚙️ Возможности системы

### Что умеет модуль на C++:
*   **Разметка зон (Режим редактора)**: Администратор может разметить парковочные места прямо на кадре с камеры без изменения кода программы.
*   **Мониторинг в реальном времени**: Система анализирует видеопоток по протоколу RTSP и определяет занятость мест с помощью классического алгоритма компьютерного зрения (детектор границ Кэнни).
*   **Распознавание государственных номеров (ANPR)**: Система считывает номера въезжающих автомобилей. Это необходимо для подтверждения бронирований, сделанных через Telegram-бот, и контроля доступа.
*   **Формирование статуса**: Программа непрерывно обновляет текстовый файл `status.txt`, содержащий актуальное количество свободных мест.
*   **Визуализация**: На экране отображается видеопоток с наложенными рамками (красные — занято, зеленые — свободно).

### Что умеет Telegram-бот:
Бот работает в двух режимах и имеет две роли пользователей:
*   **Для клиентов (водителей)**: Проверка наличия свободных мест в реальном времени, а также функция предварительного **бронирования места**. При бронировании клиент вписывает свой госномер, чтобы система распознала его при въезде.
*   **Для владельцев (администрации)**: Получение сводной информации о количестве занятых/свободных мест по команде, просмотр статистики загрузки парковки.

## 🧠 Технические особенности и принцип работы

### Почему не использована нейросеть (YOLO)?
На этапе проектирования мы протестировали популярную нейросеть YOLOv4. Однако было выявлено, что стандартные модели плохо распознают автомобили при виде **строго сверху**, так как обучались на ракурсах сбоку. 

Поэтому для детекции занятости было принято решение использовать **детектор границ Кэнни (Canny Edge Detector)**. Принцип работы основан на физических свойствах: пустой асфальт — это гладкая поверхность с минимумом границ, а автомобиль — это сложный объект с множеством контуров (окна, двери, колеса). Если количество найденных границ в зоне превышает 5% от её площади, система считает место занятым. Это решение работает в разы быстрее и стабильнее на слабом оборудовании.

## 🛠️ Инструкция по запуску

### Требования
*   **ОС**: Windows
*   **Среда разработки**: Visual Studio 2022
*   **Библиотеки**: OpenCV 4.7.0 (или выше)
*   **Камера**: IP-камера с поддержкой RTSP-потока.

### Настройка проекта
1. В свойствах проекта Visual Studio укажите пути к папкам `include` и `lib` библиотеки OpenCV.
2. В настройках компоновщика добавьте библиотеку `opencv_world470d.lib`.
3. В свойствах отладки установите **Рабочую директорию** в значение `$(OutDir)`.

### Использование программы

Программа имеет два режима работы, которые запускаются через аргументы командной строки.

#### 1. Режим разметки зон (Редактор)
Запуск с флагом `--edit`:
1. В свойствах проекта перейдите в раздел **Отладка**.
2. В строке **Аргументы команды** напишите: `--edit`.
3. Запустите программу (F5). Откроется кадр с камеры.
4. Зажмите левую кнопку мыши и обведите каждое парковочное место.
5. Нажмите **ESC**, чтобы сохранить разметку в файл `zones.txt`.

#### 2. Режим мониторинга (Основной)
1. В свойствах проекта **очистите** строку **Аргументы команды** (оставьте пустой).
2. Запустите программу (F5).
3. Система подключится к камере, считает файл `zones.txt` и начнет мониторинг. Выход по клавише **ESC**.

### Telegram-бот
Для запуска бота:
1. Установите библиотеку: `pip install pyTelegramBotAPI`.
2. Вставьте токен вашего бота в файл `bot.py`.
3. Запустите скрипт и напишите боту команду `/start`.
