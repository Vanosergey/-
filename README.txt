# Система управления парковочными местами

## Как система работает в реальных условиях

1. Камера (Tapo C200/C310) закрепляется стационарно на высоте 2–3 м 
   с обзором парковочных мест (например, на стене школы или столбе 
   у въезда). Камера подключается по Wi-Fi, поток идёт по RTSP.
2. При первом запуске администратор размечает зоны: открывает эталонный 
   кадр с камеры и вручную задаёт координаты каждого места в файле zones.txt.
3. Далее система в реальном времени определяет занятость мест 
   и передаёт данные в Telegram-бот и на светодиодную индикацию.

## Почему в прототипе координаты заданы вручную

На этапе прототипа камера не закреплена стационарно, поэтому 
координаты зон задаются вручную и могут быть пересчитаны под любую сцену. 
В реальной эксплуатации камера стационарна, и разметка делается один раз.

## Ограничения прототипа

- Зоны задаются вручную (в финальной версии — автоматическая детекция 
  свободного пространства).
- Определение занятости — по яркости ROI (заглушка), 
  в финальной версии — YOLO-детекция автомобилей.
